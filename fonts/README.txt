The kanji in the wallpapers and the seal (src/glyphs.json) are vector outlines
extracted from Shippori Mincho ExtraBold by the Shippori Mincho Project Authors
(https://github.com/fontdasu/ShipporiMincho), licensed under the SIL Open Font
License 1.1 (OFL-ShipporiMincho.txt). Only the few characters the artwork uses
are included; rebuild them with `python3 src/glyphs.py build`.

The terminal configs use JetBrains Mono Nerd Font (OFL), installed separately:
  brew install --cask font-jetbrains-mono-nerd-font
